# 异想物理 · 第一关：光滑仓库

从生活里的“如果”进入物理世界。玩家先选择关注对象，再亲手改变条件并观察运动。

## 本地运行

```sh
npm start
```

打开 http://localhost:5173 。核心物理模型可用 `npm test` 验证。

## 第一关

人物、箱子和墙会轮流闪烁虚线框，提示可以选择。点选可将对象加入研究系统；再次点选会移出。观察人、箱子和墙的组合，尝试走路、抛出箱子，并在出口处抓住扶手。概念说明按需展开。

## 模型假设

一维水平方向，人质量 60 kg，箱子各 10 kg。地面无摩擦，忽略空气阻力；抛出瞬间使用动量守恒。墙与地球近似为巨大的动量储库。具体假设在游戏内“模型与假设”中说明。

## 部署

这是纯静态 HTML、CSS 和 JavaScript，无后端依赖。将 `public/` 放入 Nginx 网站目录，并以 `nginx.conf.example` 为配置参考。域名 A 记录应指向服务器公网 IP；HTTP 访问需要开放 TCP 80。
